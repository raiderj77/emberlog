# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include secrets, personal data, or exploit details in a public discussion.

Use [GitHub's private vulnerability reporting form](https://github.com/raiderj77/emberlog/security/advisories/new). Include the affected page or component, steps to reproduce, the potential impact, and any suggested mitigation.

The maintainer will acknowledge a complete report as soon as practical, assess its severity, and coordinate remediation and disclosure through the private advisory.

## Supported version

The production deployment from the `main` branch is the supported version.
